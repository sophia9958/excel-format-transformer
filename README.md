你是否经历过：从系统导出的原始数据有 100 多列，但你只需要其中 5 列填进特定的汇报模板？

手动删减、反复匹配、还要担心算错时长总和？

此工具旨在解决媒体、行政、财务等行业中，由于系统导出表（表 A）与交付模版（表 B）字段不统一而导致的繁琐匹配工作。

 🌟 核心亮点

* 零代码门槛：专为非技术背景的专业人员设计，传表即用。
* 智能表头对齐：基于文字相似度算法，自动匹配 A/B 表字段，支持行业特征词（如片单、编码、状态等）动态自定义，支持手动修改。
* 硬核时长处理：专门优化了超过 24 小时的时间累计逻辑，支持 `[h]:mm:ss` 格式，彻底解决影视、工时统计等场景的痛点。
* 无名列安全预警：当源表出现空表头时，系统会强制触发红色警报并提供内容预览，拒绝盲目乱配，确保数据对齐万无一失。
* 一键错误反馈：内置排错日志复制功能，遇到 Bug 一键带走，极大简化了售后沟通流程。

 2. 本地部署 (开发者专区)
如果你想把这个工具部署在自己的电脑或公司服务器上，请自取源码：
1. 克隆本仓库到本地。
2. 运行 `pip install -r requirements.txt` 安装依赖（系统已内置兼容老古董 `.xls` 文件的 `xlrd` 及新款 `.xlsx` 的 `openpyxl` 等关键组件）。
3. 执行 `streamlit run app.py` 启动服务。
