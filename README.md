# 🔀 万能 Excel 表头提取与匹配助手

还在用 VLOOKUP？

还在无限复制粘贴？

还在几张 Excel 表之间反复横跳、查找和核对字段？

你是否经历过：

> 系统导出的原始数据有 100 多列，但你只需要其中几列，按照另一份模板的字段和 Sheet 结构完成交付。

手动删减不仅耗时，还可能出现字段错位、数据重复、Sheet 分错、时长格式异常等问题。

本工具用于解决媒体、行政、财务、运营等场景中，由于系统导出表（表 A）与目标模板（表 B）字段不统一而产生的繁琐匹配工作。

上传表 A 和表 B 后，系统会自动匹配字段，并按照表 B 的字段结构和 Sheet 名称生成新的 Excel 文件。

---

## 🌟 核心亮点

### 零代码门槛

专为非技术背景的使用者设计。无需编写公式或脚本，上传表格、确认规则、下载结果即可。

### 智能字段匹配

系统会根据字段名称和文字相似度，自动匹配表 A 与表 B 的字段。

例如：

- 表 A 的“片单编码”可以对应表 B 的“编码”
- 表 A 的“节目名称”可以对应表 B 的“片单名称”
- 名称无法自动匹配时，可以手动指定“表 B 字段＝表 A 第几列”

表头定位特征词支持自定义，因此不限于影视行业，也可以处理行政、财务、库存、课程、项目等不同类型的表格。

### 支持表 A 和表 B 多 Sheet

表 A 可以包含一个或多个有效 Sheet，系统会读取并汇总其中的数据。

表 B 可以包含多个目标 Sheet，最终导出的文件会保留表 B 的 Sheet 名称和字段结构。

### 自定义多 Sheet 分流

当表 B 有多个 Sheet 时，可以选择用于分流的字段，例如：

- 分类
- 子分类
- 部门
- 地区
- 渠道
- 状态
- 项目类型

然后为表 B 的每个目标 Sheet 勾选允许接收的字段值。

规则关系：

- 同一个字段选择多个值：满足其中任意一个即可
- 同一个 Sheet 设置多个字段：必须同时满足
- 表 B 已有编码、ID、编号、名称或标题能够匹配时：优先自动归属
- 同时符合多个 Sheet：判定为冲突，不擅自写入
- 不符合任何 Sheet：判定为未归属，不擅自写入

分流逻辑完全由表格内容和用户选择决定，不内置影视、财务或其他行业的固定分类规则。

### 超过24小时的时长处理

针对影视总时长、课程时长、累计工时等场景进行了优化。

系统支持 `[h]:mm:ss` 格式，可以正确显示超过24小时的累计时长，避免 Excel 自动折算后出现时间显示错误。

需要转换的时间字段可以在页面中自行勾选。

### 缺失字段默认填充

如果表 B 中存在表 A 没有的字段，可以设置默认值，例如：

```text
更新日期=260713
是否成品=是
```

不同字段可以设置不同的默认内容；未设置的字段会保留为空。

### 无名列安全预警

当表 A 出现空表头，但该列实际存在内容时，系统会显示警告及内容预览。

使用者可以根据预览，在“手动对号修正”区域指定该列应当对应表 B 的哪个字段，避免系统盲目匹配。

### 清晰的转换结果预览

处理完成后，页面会按照表 B 的目标 Sheet 展示结果，例如：

```text
表B目标 Sheet『4K少儿』
写入数据：13条
成功匹配：20个字段
填充/留空：1个字段
```

请注意：

- “写入数据”表示写入该 Sheet 的数据行数
- “成功匹配”表示成功对应的字段（列）数
- “填充/留空”表示使用默认值或留空的字段（列）数
- 预览中显示的 Sheet 名称均来自表 B

展开预览后，还可以查看表 A 每一列具体对应到了表 B 的哪个字段。

### 一键复制排错信息

页面内置排错日志。

如果发生字段未匹配、记录未归属或其他异常，可以一键复制诊断信息，方便反馈问题，无需反复截图或口头描述。

## 🚀 快速开始

### 1. 在线使用

无需安装，直接在浏览器中打开：

👉 [点击体验：万能 Excel 提取助手](https://sophia-excel-format-transformer.streamlit.app)

基本操作流程：

1. 上传表 A：系统导出的原始数据
2. 上传表 B：包含目标字段和目标 Sheet 的模板
3. 检查系统识别的表头行
4. 根据需要设置默认值和手动字段映射
5. 如果表 B 有多个 Sheet，选择分流字段和各 Sheet 的允许值
6. 查看每个 Sheet 的写入条数及字段匹配情况
7. 下载转换后的 Excel 文件

### 2. 本地部署

如果需要在自己的电脑或公司服务器上运行：

1. 克隆本仓库到本地
2. 安装依赖：

```bash
pip install -r requirements.txt
```

项目依赖中应包含：

- `streamlit`
- `pandas`
- `openpyxl`
- `xlrd`

其中：

- `xlrd` 用于读取旧版 `.xls` 文件
- `openpyxl` 用于读取和生成 `.xlsx` 文件

3. 启动服务：

```bash
streamlit run app.py
```

## 📌 表 A 和表 B 分别是什么？

### 表 A：原始数据表

一般是从业务系统导出的数据，字段可能很多，顺序也不一定符合交付要求。

表 A 提供最终需要写出的数据内容。

### 表 B：目标模板

表 B 决定最终文件的：

- Sheet 名称
- 字段名称
- 字段顺序
- 目标结构

简单来说：

> 表 A 提供数据，表 B 决定输出格式和数据去向。

## 🧭 多 Sheet 分流示例

假设表 B 包含以下目标 Sheet：

- 华东区
- 华南区
- 华北区

可以在“多 Sheet 分流规则”中选择字段“地区”，然后分别设置：

- 华东区：上海、江苏、浙江
- 华南区：广东、广西、海南
- 华北区：北京、天津、河北

如果还需要同时区分业务状态，可以再增加“状态”字段。

例如“华东区”设置为：

- 地区：上海、江苏、浙江
- 状态：已审核

此时只有同时满足两个条件的数据才会进入“华东区”。

## ⚠️ 使用提示

- 第一次使用新模板时，请检查系统识别的表头行是否正确。
- 分流字段应优先选择取值较少、含义明确、能够区分 Sheet 的字段。
- 不建议使用简介、备注等长文本作为分流字段。
- 如果两个 Sheet 选择了重叠规则，相关记录可能被判定为冲突。
- 如果某个 Sheet 显示“写入数据：0条”，说明本次没有数据符合该 Sheet 的分流规则。
- 下载前建议展开预览，检查写入条数和字段对应关系。
- 上传新模板后页面状态异常时，可以使用 Streamlit 右上角菜单中的 Rerun 或 Clear cache。
