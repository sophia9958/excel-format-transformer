# 🔀 万能 Excel 表头提取与匹配助手

还在用 VLOOKUP 一个字段一个字段地找？

还在几张 Excel 表之间反复横跳、复制粘贴？

系统导出的原始表有几十甚至上百列，但交付时只需要其中几列，还要换字段名、补默认值、分到不同 Sheet？

这个工具就是来处理这些麻烦事的。

你只需要上传两份表：

- **表 A：原始数据表**，例如从系统导出的完整数据。
- **表 B：目标模板表**，决定最终需要哪些字段、生成哪些 Sheet。

工具会自动寻找表 A 和表 B 中相同或相似的字段，把表 A 的数据提取出来，按照表 B 的字段结构生成新的 Excel。

如果表 B 有多个 Sheet，还可以设置分流规则，让不同的数据进入不同的目标 Sheet，不再出现“虽然分了 Sheet，但每个 Sheet 内容都一样”的问题。

---

## 🌟 核心功能

### 1. 自动匹配字段

系统会自动比较表 A 和表 B 的字段名称。

例如：

- 表 A 叫“节目编码”，表 B 叫“编码”
- 表 A 叫“片单简介”，表 B 叫“简介”
- 表 A 叫“版权结束日期”，表 B 叫“版权结束”

名称相同或相似时，系统会尝试自动对应。

处理完成后，页面会清楚显示：

> 表 A 第几列 → 表 B 第几列

方便你在下载前检查有没有配错。

### 2. 支持手动指定字段

如果自动匹配不准确，可以直接告诉系统：

> 表 B 字段 = 表 A 第几列

例如：

```text
许可证=10
```

表示表 B 的“许可证”字段使用表 A 第 10 列的数据。

### 3. 支持表 B 多个 Sheet

如果表 B 有多个 Sheet，工具会保留这些目标 Sheet 的名称，并把表 A 数据分别写入对应的 Sheet。

你可以选择“分类、部门、地区、渠道、状态”等字段作为分 Sheet 条件，再为每个 Sheet 勾选允许接收的值。

例如：

- 华东区 Sheet：地区选择“上海、江苏、浙江”
- 华南区 Sheet：地区选择“广东、广西、海南”
- 已完成 Sheet：状态选择“已完成”
- 待处理 Sheet：状态选择“待处理”

规则很简单：

- 同一个字段选择多个值：满足其中任意一个即可。
- 同一个 Sheet 设置多个字段：必须同时满足。
- 同一条数据符合多个 Sheet：系统不会随便乱放，会提示规则冲突。
- 数据不符合任何 Sheet：系统不会硬塞进去，会提示未归属。

程序不会内置“影视、财务、行政”等行业判断，所有分流都根据你的表格内容和选择的规则完成。

### 4. 表 A 也可以有多个 Sheet

如果表 A 有多个非空 Sheet，工具会读取并合并这些数据，再根据表 B 的结构和分流规则进行处理。

空 Sheet 会自动跳过。

### 5. 自动填默认值

如果表 B 需要某个字段，但表 A 中没有，可以设置默认内容。

例如：

```text
更新日期=260713
是否成品=是
处理状态=待审核
```

没有设置默认值的字段会留空。

### 6. 超过24小时的时长也能处理

普通 Excel 时间格式超过24小时后，显示结果经常不符合预期。

本工具支持将时长字段转换为：

```text
[h]:mm:ss
```

适用于：

- 影视节目总时长
- 课程累计时长
- 工时统计
- 设备运行时间

哪些字段需要转换，可以在页面中自行勾选。

### 7. 无名列预警

如果表 A 某一列有数据却没有字段名，系统会显示警告，并提供该列的内容预览。

你可以根据预览内容，通过“手动对号修正”指定它应该对应表 B 的哪个字段，避免系统盲目匹配。

### 8. 表头位置可以手动修正

有些 Excel 的第一行是大标题，第二行或第三行才是真正的字段名。

工具会自动尝试寻找表头，也允许你为表 B 的每个 Sheet 单独指定：

> 字段名在第几行

### 9. 转换结果看得明白

处理完成后，每个目标 Sheet 会显示：

```text
表B目标 Sheet『示例名称』
写入数据：13条
成功匹配：20个字段
填充/留空：1个字段
```

这里：

- **写入数据**：实际写入该 Sheet 的数据行数。
- **成功匹配**：表 B 中有多少字段找到了表 A 的对应列。
- **填充/留空**：有多少字段使用默认值或保持空白。
- 页面显示的 Sheet 名称：都是表 B 的目标 Sheet 名称。

### 10. 一键复制排错信息

如果处理结果不对，可以打开页面底部的“排错专区”，一键复制诊断信息。

诊断内容包括：

- 表 A 的字段
- 表 B 每个 Sheet 识别到的表头
- 每个 Sheet 实际写入多少条数据
- 无法归属的数据行
- 字段匹配情况

这样反馈问题时，不需要再手动描述半天。

## 🚀 在线使用

不需要安装软件，直接在浏览器中打开：

👉 [点击使用：万能 Excel 提取助手](https://sophia-excel-format-transformer.streamlit.app)

基本操作：

1. 上传表 A，也就是原始数据表。
2. 上传表 B，也就是目标字段模板。
3. 检查系统识别的表头行。
4. 如有需要，设置默认值或手动字段映射。
5. 如果表 B 有多个 Sheet，选择分 Sheet 字段。
6. 为每个目标 Sheet 勾选允许接收的字段值。
7. 检查“写入数据条数”和“字段匹配情况”。
8. 下载转换后的 Excel。

建议第一次使用新模板时，先用少量数据测试，确认字段对应和分流规则正确后，再处理完整文件。

## 💻 本地部署

如果希望部署在自己的电脑或公司服务器上：

1. 克隆本仓库。

2. 安装依赖：

```bash
pip install -r requirements.txt
```

项目支持：

- `.xls` 老格式文件：使用 `xlrd`
- `.xlsx` 新格式文件：使用 `openpyxl`

3. 启动服务：

```bash
streamlit run app.py
```

4. 根据终端显示的地址，在浏览器中打开网页。

## 🗺️ 意见反馈

目前工具可以处理大部分日常字段提取、字段转换和多 Sheet 分流任务。

不过，真实世界里的 Excel 总能长出一些意想不到的格式。

如果遇到以下情况，欢迎反馈：

- 表头识别错误
- 字段匹配不准确
- 数据进入了错误的 Sheet
- 出现未归属或规则冲突
- `.xls` 或 `.xlsx` 文件读取失败
- 时长显示不正确
- 下载结果与预期不一致

反馈时，请尽量附上页面“排错专区”的诊断信息。
